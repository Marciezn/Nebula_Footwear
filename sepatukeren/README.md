## Dashboard_Admin

1️⃣ Sidebar Kiri (Navigasi Utama)
Bagian ini berfungsi untuk perpindahan halaman dalam sistem admin NebulaAdmin.
Dashboard → Halaman ringkasan performa (halaman yang sedang dibuka)
Customers → Manajemen data pelanggan
Kategori → Pengelompokan produk
Produk → Manajemen produk
Pengaturan → Konfigurasi sistem
Logout → Keluar dari akun admin
👉 Sidebar dibuat gelap agar kontras dengan konten utama dan memudahkan fokus.

2️⃣ Header Atas
🔹 Sambutan Admin
“Selamat datang, Admin”
Pantau performa bisnis & tim pekerja
Ini adalah informasi kontekstual, menegaskan bahwa dashboard dipakai untuk:
Monitoring bisnis

Refresh → Memuat ulang data terbaru
Export Data → Mengunduh data (biasanya CSV / Excel)
👉 Fungsinya untuk kontrol data cepat tanpa pindah halaman.

## Login

Fungsi Halaman Login

Autentikasi Pengguna
Memverifikasi apakah email dan password yang dimasukkan sesuai dengan data di sistem.

Kontrol Akses
Membatasi agar hanya pengguna yang memiliki akun yang bisa masuk ke sistem.

Keamanan Sistem
Mencegah akses ilegal ke halaman admin atau data penting.

Identifikasi Pengguna
Menentukan peran pengguna (misalnya admin atau user) setelah berhasil login.

Gerbang ke Sistem Utama
Mengarahkan pengguna ke dashboard atau halaman utama setelah login berhasil.

### Produk_user

Mempermudah Proses Pembelian

Menghapus Data Pelanggan
Tombol Delete berfungsi menghapus data pelanggan dari sistem.

Kontrol & Validasi Data
Membantu admin menjaga data pelanggan tetap rapi, valid, dan terorganisir.

## Produk_admin

Fungsi Bagian Produk (Admin)

Menampilkan Daftar Produk
Menyajikan seluruh produk yang tersedia lengkap dengan gambar, nama, kategori, harga, dan stok.

Manajemen Data Produk
Admin dapat menambah, mengubah, dan menghapus data produk.

Pencarian Produk
Memudahkan admin mencari produk tertentu dengan cepat.

Pengelompokan Produk
Mengaitkan produk dengan kategori untuk pengaturan yang terstruktur.

Pengaturan Harga
Menentukan dan memperbarui harga produk.

Manajemen Stok
Mengontrol jumlah stok agar ketersediaan produk tetap terpantau.

Kontrol Penjualan
Memastikan hanya produk yang valid dan tersedia yang dapat dijual ke pelanggan.
