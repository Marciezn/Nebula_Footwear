Refresh → Memuat ulang data terbaru
Export Data → Mengunduh data (biasanya CSV / Excel)
👉 Fungsinya untuk kontrol data cepat tanpa pindah halaman.

## Login

Fungsi Halaman Login

Autentikasi Pengguna
Memverifikasi apakah email dan password yang dimasukkan sesuai dengan data di sistem.

Kontrol Akses
Membatasi agar hanya pengguna yang memiliki akun yang bisa masuk ke sistem.

Keamanan Sistem
Mencegah akses ilegal ke halaman admin atau data penting.

Identifikasi Pengguna
Menentukan peran pengguna (misalnya admin atau user) setelah berhasil login.

Gerbang ke Sistem Utama
Mengarahkan pengguna ke dashboard atau halaman utama setelah login berhasil.
